# Extractingo

Free browser-only email and URL extractor. A Scoutier product.

Paste or drop `.txt`, `.csv`, `.pdf`, or `.docx`. Extract emails (personal vs domain, Gmail-only, unique, chunked) or unique domains. Nothing is uploaded.

```bash
npm ci
npm run dev
```

Opens at `http://localhost:8080`. Production target: `https://extractingo.scoutier.com.ng`. See [docs/deploy.md](docs/deploy.md).
